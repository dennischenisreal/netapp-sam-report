# 多报告 Skill 接入与管理

## 当前定位

展示名称采用 **NetApp Report Skills**，当前仓库地址与现有 SAM 文件路径保持不变。先建立清晰导航，再按实际验收结果接入更多报告，不提前重构可用功能。

| 类型 | 已有成果 | 下一步 | 不能提前宣称 |
|---|---|---|---|
| SAM | 六模块源码、分发候选包、中文指南及隔离合成验收 | 客户端 UI 和新机器试用、完善发布门槛 | 已成为所有平台认证的稳定版 |
| PA | 本仓库尚无对应可分发包 | 单独审核源码、Performance Archive 输入、指标口径、依赖和匿名测试 | 当前 SAM 包包含 PA 功能 |
| Trend | 已保留趋势 Skill 源码 | 审核月份识别、完整卷身份、历史采样与增长口径，提供独立安装指南及包 | SAM 安装入口已经交付全部趋势工作流 |

## 推荐组织方式（未来接入时采用，不是本轮已迁移）

```text
README.md                         # 三类报告的统一中文导航
docs/report-catalog.md            # 接入状态与规范
docs/reports/sam/                 # 后续分报告文档
docs/reports/pa/
docs/reports/trend/
examples/                        # 仅虚构样板及生成说明
distribution/                    # 各报告的独立安装包与精确校验文件
src/                             # 现有 SAM 源码本轮不移动
```

当前只有 README、接入规范与样板入口落地；示意的未来目录不创建空壳，不修改现有安装器、生产路径或业务调用。

## 新报告接入清单

1. 明确功能、输入格式、字段单位、版本范围、输出和失败条件；不要把 SAM 的 25 页与 14 项检查套用到 PA 或 Trend。
2. 审查业务代码、知识库依赖与原始历史；客户命名和本机路径外置，不上传真实数据。
3. 保持独立 Skill 触发条件、独立输出目录与独立安装包，不要求使用者安装不需要的报告。
4. 为每类报告提供纯虚构样板、中文安装步骤、依赖说明、单元测试及端到端验证。
5. 共享依赖仅在确有重复且完成回归后提取；不为统一目录而改坏已有功能。
6. 每个包关联对应提交、哈希、验收摘要和已知限制。源代码提交不等于正式发布，稳定 tag/Release 仍单独审批。
7. 在一个仓库管理需求与版本记录；未来确有独立发布需求，再评估分报告版本号，不擅自改现有 0.5.0 规则。

## 公开不等于已选开源许可证

仓库可公开查看与下载，但当前尚未选定 LICENSE。公共可见性本身不明确授予修改或再分发权利。许可证由维护者另行选择；接入第三方代码与依赖前核对其许可证，不代替维护者擅自选 MIT、Apache 或其他条款。
